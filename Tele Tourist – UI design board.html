Tele Tourist
interface design board

Seven screens, one system. Navigation lives in a single top bar, so every page gets its full width, and each page has its own layout: a split screen for sign-up, a masonry wall for exploring, a photo mosaic for reading, a live preview for writing.

Everything here is plain HTML and CSS that maps onto Bootstrap's grid, navbar and modal, with jQuery handling the filters, likes and saves.
